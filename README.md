# Karnevals-Buddy

A small offline web app for the Karneval season: next event with a countdown, costumes, a packing list per event and notes.

Open https://leonmanuel0705.github.io/karnevals-buddy/ in Safari on the iPad, tap Share, then "Zum Home-Bildschirm", and open it once from the home screen. After that it runs without internet. All entries stay on the device.
